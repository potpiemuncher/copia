# Getting help

- **Something is broken or a number looks wrong:** open a
  [bug report](https://github.com/potpiemuncher/copia/issues/new?template=bug_report.yml).
  The output of `copia --print` helps a lot; it contains no tokens, but read it
  before pasting.
- **A tool you use is missing:** open a
  [provider request](https://github.com/potpiemuncher/copia/issues/new?template=provider_request.yml),
  or add it yourself as a custom command (see the README's Settings section).
- **A security problem:** see [SECURITY.md](SECURITY.md); please do not open a
  public issue.
- **Anything else:** email **support@pulsarit.ca**.

This is a spare-time project, so replies may take a few days.
