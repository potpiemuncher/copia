# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

The interface is a web page inside a Tauri 2 desktop shell: a tray icon drawn
in Rust plus one popover window rendering `ui/index.html` (with `ui/style.css`
and `ui/app.js`). It is not a website
and has no browser chrome, URL or scrolling page.

## Users

Developers who pay for two or more AI coding subscriptions (Claude, Codex /
ChatGPT, Gemini, OpenCode and similar). They glance at Copia in the middle of
a task to decide which tool still has room, then go straight back to work.

## Product Purpose

Copia shows how much of each AI coding subscription is left. It sits in the
macOS menubar or the Windows / Linux system tray; the tray icon is itself a
small chart, and clicking it opens labelled vertical bars, one per quota
window, filled to what remains.

Success is a user answering "which tool can I still use, and when does the
other one come back?" in one glance, without opening a terminal or a vendor
dashboard.

The idea came from @zip.mu.social on Rainshare
(https://rainshare.dev/seed/zip.mu.social/3n2v6joikno2l).

## Positioning

One small tray app that is the same on macOS, Windows and Linux. Neighbouring
tools are either macOS-only with a very long provider list (CodexBar) or tied
to one platform or one vendor. Copia chooses breadth of platforms over breadth
of providers.

## Operating Context

- Lives in the menubar / system tray alongside the user's editor and terminals.
- Left click toggles the popover; clicking elsewhere or pressing Esc dismisses
  it. Ctrl+R / ⌘R refreshes. Right click
  opens a menu (Show quotas, Refresh now, Quit). On Linux, where trays only
  expose a menu, the menu is the way in.
- Hovering the icon gives the same numbers as text.
- Data refreshes on a timer (default 5 minutes) and on demand.
- `copia --print` prints the quotas once as JSON; `--demo` shows made-up numbers.
- Installed from GitHub releases: a Windows setup, a universal macOS disk
  image, and a Linux `.deb` and AppImage. None is code-signed, so Windows and
  macOS warn on first run.
- Optional `config.json` sets the refresh interval, disables providers and
  adds custom providers (any command that prints quota JSON).

## Capabilities and Constraints

- Built-in providers: Claude, Codex, Gemini CLI, OpenCode Go. Each reuses the
  sign-in that vendor's own CLI left on the machine and asks that vendor's
  usage endpoint. Only OpenCode Go's endpoint is documented by its vendor; the
  others are what the vendors' own tools call and can change without notice.
- A provider with no sign-in on the machine is left out. A provider whose
  fetch fails shows its error in place of its bars.
- Each quota has a short label ("5h", "week", "pro"), a used fraction and an
  optional reset time. Bars show what is *left*.
- The tray icon shows one bar per provider: what is left of its tightest quota.
  On macOS it is a template image tinted by the system; elsewhere bars are
  coloured by level.
- Terminology: "provider" (a tool/vendor), "quota" (one window of one
  provider), "left" / "remaining" for the fraction shown.
- Not built: Antigravity, OpenCode Zen balance, Cursor, Copilot.
- A provider nobody has run against a live account is flagged experimental
  and shown as "unverified" in the popover. Today that is OpenCode Go.
- Known gap: on macOS the popover does not appear over another app's
  fullscreen Space.
- Known gap: Gemini is also untested against a live account but is not yet
  flagged "unverified" in the app.
- Known gap: OpenCode v2 keeps credentials in a SQLite database Copia does not
  read; those users must set `OPENCODE_API_KEY`.
- Undecided: whether Copia ever refreshes expired tokens itself; whether it
  gains alerts, history or cost estimates.

## Product Principles

1. **A glance, then gone.** The user is mid-task; every interaction should be
   answerable in a second and dismissable without thought.
2. **Same on every desktop.** A feature that can only exist on one OS is
   suspect; platform differences are accommodated, not showcased.
3. **Borrow, never hold.** Credentials are read only: Copia never logs in,
   writes or refreshes a token, and each token goes only to its own vendor.
4. **Nothing leaves the machine for Copia.** No account, no server, no
   telemetry.
5. **Say what is unverified.** Providers and platforms that have not been
   confirmed are labelled as such in the app and the docs.

## Accessibility & Inclusion

The popover is held to WCAG 2.1 AA: text contrast in both light and dark
themes, each bar exposed to assistive technology as a labelled meter, full
keyboard operation, Windows High Contrast (forced colours) support, and no
motion under reduced-motion settings. Status is never conveyed by colour
alone. This has been checked in code and in a browser's accessibility tree,
not yet with a screen reader.
